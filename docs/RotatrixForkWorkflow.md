# Rotatrix fork policy

The canonical policy is [Rotatrix Fork Development and Release Workflow](https://github.com/rotatrix/oss-forks/blob/master/rotatrix-oss-fork-workflow.md).
In the shared workspace, read `oss-forks/rotatrix-oss-fork-workflow.md` before making changes.

MeshLab-specific implementation and current transition limits are in
[release promotion](RotatrixRelease.md) and [OpenAxis integration](OpenAxis.md).
The active work branch can ship through immutable tags and exact-build artifact
promotion. History cleanup and a separate maintained branch are optional.
